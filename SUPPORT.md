# Support

Use GitHub Discussions for setup help and design conversations. Use Issues for
reproducible bugs and approved feature work. Include your operating system,
Node version, Ollama version, configured model and the non-sensitive output of
`npm run doctor`.

Never attach `.env.local`, chat databases, personal documents, generated
embeddings or full Knowledge Vault indexes. Rangabot is community software and
does not provide guaranteed response times or professional medical, legal,
financial or security advice.
