# Ranga asset provenance

Ranga is the minimal golden-retriever mascot created specifically for the
Rangabot project in July 2026. The artwork was generated and refined for this
repository from a generic golden-retriever design direction; no private pet
photograph or third-party mascot artwork was incorporated.

Tracked assets:

- `ranga-idle.png` — the single optimized runtime mascot asset. Rangabot's
  restrained motion is implemented with CSS so the public application does not
  ship duplicate GIF and sprite-atlas payloads.

The project owner reviewed these files as the intended redistributable Ranga
asset set on 2026-07-28. They are licensed under CC BY 4.0 as described in
`LICENSE.md`. Future assets must document their creator, source/reference inputs,
generation or editing process, review date and license before being committed.
