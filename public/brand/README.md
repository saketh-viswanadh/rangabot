# Rangabot responsive identity provenance

This is the Founder-approved Rangabot identity set finalized on 2026-08-14. It
was generated and refined specifically for Rangabot. A third-party golden
retriever mark was used only as a high-level reference for the compact
negative-space direction; no reference pixels or source vectors are included.

The expressive primary mark belongs on product identity surfaces. The compact
Goldie mark belongs beside assistant messages at 18–24 px and must not be put
inside another badge. The spark is a restrained conversation accent, not a
replacement logo.

These files are proprietary Rangabot identity assets approved for official
Rangabot product use. Rangabot reserves all trademark rights in the name and
identity set. No redistribution license is granted for these files. Do not
infer a license from the Apache-2.0 code and documentation terms or from the
separate CC BY 4.0 terms that cover the earlier Ranga artwork.
