# Rangabot public repository identity

This directory documents the exact Founder-approved 512 px primary mark used by
the public README and stored at
[`public/brand/rangabot-primary-512.png`](../../../public/brand/rangabot-primary-512.png),
integrated on 2026-08-14. Read
[`BRAND-ASSET-MANIFEST.md`](BRAND-ASSET-MANIFEST.md) for the full responsive
usage hierarchy and surface ownership.

## Provenance

- The primary mark was created for Rangabot with OpenAI image generation from
  Founder-directed golden-retriever/R identity prompts. No private photograph
  or third-party logo was used as an input.
- The chat glyph was redrawn from scratch as a project SVG after the Founder
  supplied a generic negative-space golden-retriever image as structural
  inspiration. It copies no source pixels or exact geometry.
- The Founder reviewed and approved the visual direction on 2026-08-14.
- The PNG at `public/brand/rangabot-primary-512.png` is a byte-for-byte copy of
  the finalized 512 px asset; no repository-side regeneration, cropping or
  color conversion was performed.

## Repository scope

`public/brand/rangabot-primary-512.png` is the README hero and the core product's
canonical public asset path. Larger icon sources, smaller touch/preview
variants, chat marks and the conversation spark stay with their owning company
or core-product surfaces and are not duplicated in this documentation
directory. This PNG's presence does not by itself prove that a favicon,
application icon, social-preview setting, private website or runtime UI has
been released.

The separate CC BY 4.0 grant for `public/ranga/` has not been extended to the
new identity asset. The new identity files are proprietary Rangabot assets for
official product use, with all trademark rights reserved and no redistribution
license granted. Existing code, documentation and earlier-art licensing terms
remain unchanged; see
[`BRANDING.md`](../../../BRANDING.md).
